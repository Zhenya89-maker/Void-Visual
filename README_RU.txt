VOID VISUALS — Fabric client mod
Minecraft Java 1.21.11 | Fabric | Fold Craft Launcher (Android)

В этой версии добавлен VOID MUSIC — встроенный музыкальный плеер с тремя
оригинальными короткими ambient-треками, которые идут в комплекте с модом.
Музыка воспроизводится через звуковую систему Minecraft и продолжает играть,
когда панель закрыта или открыто другое игровое меню.

УПРАВЛЕНИЕ (можно переназначить в Настройки → Управление → VOID VISUALS):
- Right Shift — открыть/закрыть меню VOID VISUALS.
- M — показать/скрыть музыкальную панель в верхней правой части HUD.
- P — Play / Pause.
- N — следующий трек.
- 1 — VOID NIGHT.
- 2 — DARK SPACE.
- 3 — WHITE DREAM.

В музыкальной панели отображаются текущий трек, состояние воспроизведения и
анимированный эквалайзер. Выбор трека клавишами 1–3 сразу запускает его.

СБОРКА:
1. Нужны Java 21 и интернет на компьютере или Android-среде, поддерживающей Gradle.
2. Откройте терминал в папке проекта и выполните: gradle build
3. JAR появится в build/libs/void-visuals-1.0.0.jar
4. Перенесите JAR в папку mods игровой установки Minecraft 1.21.11 + Fabric.
   Также установите Fabric API той же версии.

ВАЖНО:
Это исходный проект, а не готовый проверенный JAR. В среде создания не было
доступного Gradle и доступа к репозиториям зависимостей, поэтому сборка и запуск
в Fold Craft Launcher не были проверены. Если Gradle сообщит об ошибке API,
проект нужно будет скорректировать под фактическую сборку Fabric 1.21.11.
